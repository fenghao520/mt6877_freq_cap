快捷操作

四层恢复方案

① 本页「立即恢复不限」→ 两簇写回 -1 并保持放开（守护仍在跑，点任一档位即重新接管）；「停用限频」→ 持久停用。

② 模块级 KSU 管理器里移除本模块并重启 → uninstall.sh 自动把两簇写回 -1。

③ 全局级 新建 /data/adb/modules/.disable_modules 后重启 → 禁用全部模块。

④ ADB 手动

adb shell su -c "echo -1 > /proc/ppm/policy/cluster_0_max_freq; echo -1 > /proc/ppm/policy/cluster_1_max_freq"

本模块只做运行时 /proc 写入，不动 boot 分区，重启即自动清空全部限制，因此不存在刷入后无法开机的情况。

工作原理

守护每 3 秒（熄屏 12 秒；开启深睡后熄屏也是 3 秒）巡检一次前台应用，判定 日用 / 游戏 场景后，把该场景所选档位对应的频率上限写进 MTK PPM 节点 cluster_0_max_freq（A55 小核）、cluster_1_max_freq（A78 大核）。

只限制最高频率，不碰 governor、不锁频、不改调度策略——系统该降就降、该升就升，相当于把天花板压下来。

深度睡眠（v1.2.0 新增）

熄屏且未充电、未放音并持续 20 秒后，接管系统 Doze：把白名单应用加进系统白名单、 其余用户应用移出，并写入更短的 device_idle_constants，然后 force-idle 直接进入深度休眠。亮屏、插电或放音立即逐项还原。

只收窄「用户级」白名单，系统自带的来电 / 短信 / 闹钟 / IMS 条目一律不动。接管前会把原值与改动清单 落盘，守护被杀、模块卸载、重新开机都会照它补还原，不会残留系统状态。

实验功能 · 全部拉满（v1.2.5 新增）

首页那个开关。开启后立刻全局生效并覆盖日用/游戏模式：CPU 两簇上下限贴死、GPU 锁到 OPP 最高档、DDR 锁到最高档。 关闭立即恢复成原来的日用/游戏模式。

仅供跑分使用：功耗与发热显著上升，长时间使用建议配外部散热器，玩游戏前请先关闭。

用到的节点：CPU 走我们自己的 PPM 通道（有把握）；GPU / DDR 走 MTK 的通用接口 （gpufreqv2/fix_target_opp_index、helio-dvfsrc/dvfsrc_force_vcore_dvfs_opp）， 本机是否支持由守护开机探测后上报，不支持的会在开关下方标成「本机无」—— 做不到就如实说，不假装成功。

这些节点都是内核运行时状态，重启一定清零，所以即使还原失败也不会留下永久影响； 但停用模块、卸载、重新开机时仍会照快照尝试还原。

自愈机制：内核里这几个值不是本模块独占的，别的组件也能改。所以守护每轮都会复查， 发现被改回去就立刻写回（CPU 每 3 秒查、GPU/DDR 每约 15 秒查）。开启了自愈次数会显示在开关下方 —— 正常情况下应该一直是 0；不是 0 就说明有别的组件在和它抢，可以据此排查冲突。

刷新率管理（v1.2.4 新增）

亮屏时按当前场景把刷新率锁定在你选的档位，熄屏自动交还系统（息屏显示不受影响）， 亮屏再锁回来。用的是 AOSP 标准设置项 min_refresh_rate / peak_refresh_rate， 和系统设置里那一项是同一个东西，不会互相抢。

动手前会把你的原值落盘（rrate.saved）；关闭功能、停用模块、卸载、重新开机都会照它还原。 没有快照时绝不动你的设置。

本机（Redmi Note 11 Pro+）实际支持 60 / 120 Hz 两档 —— 日用限 60 Hz 能省不少电， 但滑动会明显不如 120 Hz 跟手，所以默认关闭，自己权衡。

夜间放宽巡检（v1.2.4 新增）

深睡开启时，熄屏本来每 3 秒巡检一次；0~6 点放宽到 10 秒，减少整夜的无谓唤醒。 代价是夜里拿起手机后，恢复限频最多晚 10 秒。深睡宽限计时是跨轮累计的， 所以不会影响「熄屏满 20 秒进深睡」。

约定

  • 写入用 kHz；写 0 会被内核解释成最低档，所以「不限」必须写 -1，模块已在底层代转。
  • 节点读回的是该簇 OPP 表的降序索引：A55 = 0~15 对应 2000~500 MHz，A78 = 0~15 对应 2500~650 MHz（-1 = 不限）。守护已换算成 MHz 显示。
  • 熄屏自动放开限频，亮屏后按当前场景重新接管。
  • 开机后前 100 秒按「极速」跑，避免开机卡顿（只认系统开机时长，WebUI 重启守护不会触发）。
  • 游戏名单：config/games.list（内置）；漏掉的游戏把包名按行写进 /sdcard/Android/mt6877_freq_cap/mygames.list 即可。
